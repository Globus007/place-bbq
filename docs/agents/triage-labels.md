# Triage Labels

Five canonical roles. This file maps each role to the label string in this repo's tracker.

| Role | Tracker label | Meaning |
| ---- | ------------- | ------- |
| `needs-triage` | `needs-triage` | Maintainer must evaluate the issue |
| `needs-info` | `needs-info` | Wait for more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified. Ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Do not action |

When a skill names a role, use the tracker label from this table.

Edit the tracker-label column to match the vocabulary in use.
